# Estero Salado · Aula virtual de Ecotec

Recorrido por la pasarela del Estero Salado con 19 pantallas y 30 kioscos informativos.
Funciona en el navegador de la computadora y en el navegador de Meta Quest 3 y 3S (botón **Entrar en VR**).

## Controles

- **Computadora:** W A S D o flechas para caminar, arrastrar con el mouse para mirar, Shift para ir más rápido.
- **Casco:** joystick izquierdo para caminar, joystick derecho para girar; apretar el joystick izquierdo para ir más rápido.

## Cambiar imágenes y videos

Todo el material está en `StreamingAssets/contenido`. Cada superficie tiene un código (H01 a H19, V01 a V30)
y `contenido.json` indica qué muestra cada una. Las instrucciones están en `StreamingAssets/contenido/LEEME.txt`.
